# Houston County 5.8 GHz AREDN backbone

Turn-key amateur-radio design for a 5.8 GHz AREDN triangle linking the Houston County Emergency Operations Center in Kathleen with Emory Hospital Warner Robins and Emory Hospital Perry.

The network carries on-site FreePBX voice (three phones per building), Citadel email, and MeshChat. It is a Part 97 system: licensed control operators, traffic in the clear, and no connection to hospital clinical networks.
